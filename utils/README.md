# utils/

This folder contains **general-purpose utility scripts** that don't fit a specific language or tool category.

## Naming convention
`<purpose>_<description>.<ext>` — e.g. `generate_ssh_keys.sh`, `cleanup_temp_files.py`

## Examples of what goes here
- One-off scripts for miscellaneous tasks
- Helper scripts used by other scripts
- Scripts that mix multiple tools
- Templates and boilerplate starters

# 📁 customers/danzinger

Unity local storage configuration scripts for the **Danzinger 2024** environment.

---

## job_local_storage.sh
Configures local storage paths and NFS mounts for the Unity **Job Server** — Danzinger 2024.

**Run:**
```bash
bash job_local_storage.sh
```

## web_local_storage.sh
Configures local storage paths and NFS mounts for the Unity **Web Server** — Danzinger 2024.

**Run:**
```bash
bash web_local_storage.sh
```

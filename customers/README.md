# 📁 customers

Customer-specific deployment and configuration scripts for Unity (PhenomeOne) environments.
Each subfolder contains scripts tailored to a specific customer's infrastructure.

---

## 📂 Customers

| Folder | Customer | Scripts |
|--------|----------|---------|
| `basf/` | BASF (DEV environment) | Job + Web server installation |
| `danzinger/` | Danzinger 2024 | Local storage configuration |
| `ews/` | EWS (Mumbai region) | Job + Web server installation |
| `enza-zaden/` | Enza Zaden | Job (test) + Web server installation |
| `gdm/` | GDM | Job + Web + server config |

---

> ⚠️ These scripts may contain customer-specific endpoints, bucket names, and region settings.

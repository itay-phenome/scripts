# powershell/

This folder contains **PowerShell scripts** (Windows / cross-platform).

## Naming convention
`<Verb>-<Description>.ps1` — e.g. `Get-DiskReport.ps1`, `Set-NetworkConfig.ps1`

## Examples of what goes here
- Windows system administration scripts
- Active Directory / Azure AD automation
- CI/CD helper scripts for Windows environments
- Remote management scripts
